# 现代化实施与验收记录

日期：2026-10-28。依据 `Modernization-Assessment.md` 已确认的方向，以及本轮补充确认的三项业务规则实施。范围为 A～D 阶段首版；E 的导入导出、插件和多站点管理仍为按需扩展，不属于本轮交付。

## 实现结果

| 流程 | 实现位置与行为 |
| --- | --- |
| 启动与安装 | `Program.cs`、`Data/CmsDb.cs`、`Pages/Setup*`。启动和保存数据库设置时自动建表、升级；控制台打印安装 Token，浏览器记住授权。安装完成后阻止重复安装，仍可在网页重试升级 |
| 账号与权限 | `Models/Accounts.cs`、`Services/AccountService.cs`、`Pages/Account/*`、`Pages/Admin/Users*`。Cookie + 框架 PasswordHasher；单次、到期凭证；每请求核对账号状态与本站角色 |
| 内容发布 | `Models/Content.cs`、`Services/ContentService.cs`、`Pages/Admin/Index*`、`Edit*`。编辑草稿、修订和线上指针分离；提交后的修改不改变待审修订；审批只发布选定修订 |
| 分类与标签 | 单分类、版本标签关联；公开归档关联 `PublishedRevisionId`，不读取草稿。分类删除与草稿保存使用事务保护引用关系 |
| 写作体验 | `wwwroot/js/admin.js`。变更后延迟保存；没有变化不写草稿；错误输入不重复重试；修正输入可继续保存；提交等待正在进行的保存完成；真实版本冲突拒绝覆盖 |
| 修订 | 编辑页分页浏览修订、并排对照正文与当前草稿、查看渲染结果、恢复到草稿；恢复和重新发布各自执行权限规则 |
| 前台 | `Pages/Index*`、`Post*`、`Feed*`、`Sitemap*`。数据库分页、搜索/归档、公开版本、阅读量增量、RSS、分页 sitemap、canonical 和分享信息 |
| 评论和点赞 | 评论审核、回复目标检查、关闭评论的服务端检查；原始 HTML 禁用。点赞表复合主键，重复设置喜欢幂等；当前页批量聚合，不存重复总数 |
| 媒体 | `Pages/Admin/Media*`、`MediaFile*`。文件大小、扩展名及签名检查，随机存储名、替代文本、上传者权限；图片公开读取，PDF 下载 |
| 主题 | `Services/ThemeService.cs`、`Pages/Admin/Themes*`、`ThemeAsset*`、`theme/default/*`。Fluid/Liquid 原生模板，后台 ZIP 安装/启用，模板不静态公开，后台布局不随主题变化 |
| 设置与导航 | `Pages/Admin/Settings*`、`Navigation*`。站点设置、排序及两层导航；URL 校验和父子关系校验 |
| 运行与运维 | `docs/Deployment.md`。标准 publish、ASP.NET 10 运行时、独立持久目录、错误日志及备份恢复说明 |

保持一个 Web 项目、普通实体及少量具体服务。没有引入通用仓储、自定义 UnitOfWork、Provider 链、事件总线、插件平台、旧密码回退或旧地址兼容。没有增加测试项目、模拟框架或一次性 Regression 工程。数据库与页面之间没有隐藏在模型属性里的 IO；只在实际保存、审核、恢复、删除等操作中执行必要事务。

原有迁移工作曾保留 `WordWebCMS.old/` 作为对照。新版目录的 Web Forms 残留已在此前移除；本次完成首版范围复核、保留旧版配色和欢迎文章后，按用户要求删除旧目录。解决方案仅构建新版。

## 权限规则

| 角色 | 本站能力 |
| --- | --- |
| 游客 | 读取公开内容 |
| 注册用户 | 验证邮箱后登录，评论与点赞 |
| 投稿者 | 以上能力，创建/编辑自己的文章和页面、上传自己的媒体、提交修订审核 |
| 编辑 | 管理全站内容与媒体、直接发布/审核、评论审核、分类管理 |
| 管理员 | 以上能力，管理本站用户角色、设置、导航和主题 |
| 本站封禁 | 本站已有登录票据失效；不改变其他站点角色 |

投稿者不能直接发布、修改他人内容或删除已有发布历史的内容。管理员不能通过本页修改自身角色，且必须保留至少一名管理员。共享账号的密码重置会更换 security stamp，使使用旧 stamp 的跨站登录票据在下次请求失效；站点角色由各站自己的表决定。
