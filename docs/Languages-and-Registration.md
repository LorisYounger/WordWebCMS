# 语言、注册与短链接

## 自定义语言

界面使用 `CultureInfo.CurrentCulture` / `CurrentUICulture`。内置简体中文 `zh-Hans` 和英文 `en`；已有 `zh-CN` 配置、Cookie 和译文作为简体中文读取。站点名称与描述、文章和页面的标题、摘要、正文、封面可手动提供各语言译文；不会自动机器翻译。导航名称、分类名称与评论保留用户输入。

在持久目录 `Storage:Path/languages/` 添加 UTF-8 JSON 文件，文件名是有效的 .NET `CultureInfo` 名称，例如 `fr-FR.json`、`zh-TW.json`：

```json
{
  "首页": "Accueil",
  "登录": "Connexion",
  "共 {0} 项": "{0} éléments"
}
```

可以复制 `WordWebCMS/Languages/en.json` 作为完整键列表。保留占位符 `{0}`、`{1}`，同名语言包覆盖内置对应条目。重启后，新语言出现在后台「设置 → 启用语言」中；管理员勾选启用后才出现在访客下拉列表和文章/页面编辑语言列表中。默认语言必须同时启用。未翻译的键按 CultureInfo 父级回退，`zh` 开头的语言再使用 `zh-Hans`，其他语言再使用 `en`，最后使用内置中文文本。

选择优先级是已启用的 URL `?culture=...`、访客手动选择的语言 Cookie、浏览器 `Accept-Language`、站点默认语言。浏览器语言按质量权重从高到低匹配已启用语言（包括父级）；没有对应语言时，中文系选择 `zh-Hans`，其他语言选择 `en`。没有浏览器偏好或可用匹配时使用站点默认语言。自动检测不写 Cookie；手动选择后不再被浏览器偏好覆盖。切换接口拒绝未启用语言。

前台和后台的语言下拉框选中后立即切换，只有禁用 JavaScript 时才显示提交按钮。访客切换链接使用 `/language?culture=fr-FR&returnUrl=/about`，只允许返回本站地址并移除返回地址上的旧语言参数。Cookie 保存一年；URL 语言参数仍可用于 RSS 等明确指定语言的链接。

Razor/C# 使用 `UiText.T("首页")` 和 `UiText.Format("共 {0} 项", total)`；Liquid 使用 `{{ '首页' | t }}`。用户正文、用户名和导航文字不能作为翻译键。语言包在启动时加载，更新文件后需要重启。

## 内容译文

后台「设置」可分别填写各语言的站点名称和描述。基础字段属于站点默认语言。「编辑语言」下拉框显示「站点默认语言 · 语言名称」及其他启用语言，不再提供独立的“原文”或重复的默认语言译文选项。标题、摘要、正文和封面随编辑语言一起切换，并保留表单中尚未保存的其他语言输入。

内容按字段选择目标语言和父级译文；缺少时，`zh` 开头的语言使用 `zh-Hans`，其他语言使用 `en`，仍为空则使用站点默认内容。当前选择就是站点默认语言时直接使用基础字段。此规则统一用于文章、页面、列表、近期文章、站点名称与描述和 RSS。

文章、页面及所有译文共用短链接、权限、版本号和发布状态。自动保存只更新草稿；保存修订、提交审核、发布和恢复修订都包含完整译文。不存在译文单独绕过审核发布的路径。语言停用后保留已有译文，重新启用即可继续使用。

前台列表、正文、页面标题、站点名称与描述以及 RSS 按所选语言显示。RSS 订阅地址包含 culture 参数。搜索也匹配已发布修订中的译文。界面语言包与内容译文分开维护：安装语言包不会替管理员翻译文章。

## 头像

后台设置提供可选站点头像 URL，留空时使用内置 `/WWC.png`，也用于网站图标。用户可在 `/Account/Profile` 编辑自己的头像 URL，支持站内图片路径或 HTTP(S) 地址；留空时按用户名生成默认头像。个人主页、文章作者、评论者和登录导航统一使用用户设置的头像。

## 注册模式和算术验证

- 开放注册：新账号验证邮箱后获得本站读者权限。
- 关闭注册：拒绝注册 POST，也拒绝没有本站成员记录的共享账号首次加入；已有成员仍可登录。
- 管理员审核：注册后先验证邮箱，验证完成才进入管理员审核队列；批准后才能登录。共享账号首次加入本站同样进入待审核。

在「用户」页面批准或拒绝注册；拒绝会在本站封禁，不修改共享账号在其他站点的权限。投稿者、编辑和管理员角色仍由本站管理员授予。

登录、注册、找回账号和重置密码都要求回答简单加法题。答案只保存在服务端，挑战绑定当前浏览器，十分钟过期，每次提交后作废（包括错误答案）；失败后显示新题。重启服务也会使未提交挑战失效。现有防伪令牌和按 IP 限流继续生效。

## 文章与页面

短链接直接位于根路径，例如 `/welcome` 和 `/about`。`/p/welcome` 会永久跳转到 `/welcome`；RSS、站点地图和 canonical 使用根路径。修改已发布内容的短链接不为旧名称建立重定向。

新内容的短链接输入框为空。明确保存、提交或发布时，留空则按英文标题生成，例如 `My First Post` → `my-first-post`；无法生成时使用 `new-article-编号` 或 `new-page-编号`。自动生成发生冲突时追加序号；手动输入冲突地址会拒绝发布。系统路径（如 `admin`、`account`、`setup`、`language`）不可作为短链接。

后台单独提供文章和页面入口。页面有正文、摘要、封面、草稿、修订、审核和短链接，不显示文章分类、标签、点赞、评论或侧栏。服务端也拒绝向页面发送评论和点赞。页面不进入文章列表及 RSS，进入 sitemap；发布后可在「导航菜单」加入链接。

默认主题的 RSS、站点地图及外部导航链接使用新标签页打开，并设置 `noopener noreferrer`。

## 升级与验证

当前站点结构为 v6（新增前台头像显示开关和多语言页脚，保留 v5 的用户头像 URL）。备份后，保留原配置并启动新版本，程序会自动升级数据库；未完成时可在 `/Setup` 重试，无需另跑命令。v1/v2/v3/v4/v5 数据保留，补充头像、语言、启用语言列表、内容译文和注册模式字段；默认开放注册。

功能回归项目为 `tests/WordWebCMS.Regression`。设置 `ConnectionStrings__Site` 指向可创建临时数据库的测试 MySQL，然后运行：

```powershell
dotnet build tests/WordWebCMS.Regression/WordWebCMS.Regression.csproj -c Release -o artifacts/regression-run
dotnet artifacts/regression-run/WordWebCMS.Regression.dll .
```

测试创建随机命名的 `wwcms_test_*` 数据库，使用本地 SMTP 捕获服务和 `5193` 端口，最后关闭测试站并只删除该临时数据库。不要把只允许访问现有站点库的生产连接用作此回归配置。


## 前台头像与页脚

后台「设置 → 常规」可以开启「在主页和文章中隐藏用户头像」。两款内置主题都会隐藏列表、文章作者、评论及前台导航的用户头像，作者名称与链接仍然保留；个人资料页头像、站点图标和后台头像不受影响。默认不开启，升级后保持原有显示。

「站点页脚」接受最多 10,000 字符的 Markdown，可填写版权声明、备案链接和联系方式。输出沿用正文的 HTML 清理规则，脚本及危险链接会被过滤。各语言的页脚在「站点名称、描述与页脚译文」中填写，使用既有语言回退规则；最终内容为空时显示主题默认页脚，站点地图入口保留。

## 用户管理与审核顺序

用户管理支持用户名/邮箱搜索、角色及未验证邮箱筛选、分页、逐行角色修改、封禁和从本站移除。审核队列只显示邮箱已验证且未停用的账号，服务端拒绝为未验证或已停用账号授予有效角色。新用户先完成邮件验证，再等待管理员批准；共享账号首次加入时同样遵循本站注册模式。

「从本站移除」会记录本站移除状态，撤销已有会话和登录权限，开放注册也不会自动重新加入。已发表文章、评论以及其他站点共享的账号仍保留；在「已移除」筛选中重新授予角色即可恢复。不能修改或移除当前管理员，且至少保留一位本站管理员。
